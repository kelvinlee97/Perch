# Changelog

All notable changes to Perch are documented in this file.

## Unreleased

### Added

- A local-first task workspace with Inbox, Today, and Completed sections.
- English app text for the macOS UI, shown automatically on English systems.
- Quick reminders for 10 minutes, tonight, and tomorrow.
- A single-task due reminder with completion, defer, and delete actions.
- A persistent menu command to pause reminders and bird animation immediately.
- A three-step first-run guide.
- A Developer ID, notarization, stapling, DMG, and Gatekeeper release workflow.

### Privacy

- Perch does not require an account or transmit task and usage data.
